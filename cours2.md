# Fonctions
## Integration du CI
### 1- Linter et Formater
* Linter : personnalisable ou suit le standard du language. Outil d'analyse statique de code qui détecte les erreurs potentielles, les bogues, les schémas de code inhabituels et les problèmes de style.
* Formatteur : Outil qui réécrit automatiquement le code pour se conformer à un ensemble de règles de style prédéfinies, garantissant ainsi une cohérence visuelle.
